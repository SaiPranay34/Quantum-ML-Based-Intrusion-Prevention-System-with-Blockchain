About the Project

A New Standard for Network Security

QuantumShield combines a hybrid quantum-classical machine learning model trained on 25 lakh samples from the CICIOT2023 dataset with Ethereum blockchain technology to deliver tamper-proof, real-time intrusion detection.

Every detected threat is hashed and written permanently to the Ganache blockchain ledger, giving security teams an auditable, immutable record of all network events.

Trained on 25 lakh (2,500,000) real IoT network flows from CICIOT2023
Qiskit ZZFeatureMap quantum circuit with 4-qubit entanglement
Binary + multi-class classification — 12 attack types detected
Solidity smart contract logs intrusions on Ethereum
SMTP email alerts with configurable recipients

How It Works

From network traffic to blockchain log

1

Upload or stream network traffic CSV

Select a simulation dataset or upload your own CSV with 46 CICIOT2023 network flow features. The system reads it row by row.

2

Quantum preprocessing pipeline

Each row passes through StandardScaler → PCA (4 components) → Nystroem quantum feature enhancement using ZZFeatureMap approximation.

3

Dual model inference

Binary XGBoost classifies Normal vs Attack. If attack detected, Multi-class XGBoost identifies the exact attack type from 12 classes.

4

Blockchain logging and email alert

Detected intrusions are SHA-256 hashed and written to the Ethereum smart contract via Web3.py. An SMTP email alert fires simultaneously with attack type details.
